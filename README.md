# Clase 2: Manipulación del DOM, Flexbox y Fetch

Repositorio para la **Clase 2** del curso **Programación y Desarrollo Web - Nivel 2** de **CODEX**.

En este módulo exploramos la integración de un frontend dinámico conectando maquetación responsive, eventos del usuario y consumo de APIs asíncronas.

---

## Contenido del Proyecto

- **Layout con Flexbox:** Estructuración del header y otros elementos.
- **Manipulación del DOM:** Selección de elementos (`querySelector`), manejo de eventos (`submit`) e inyección dinámica de HTML.
- **Funciones de Arreglos (`.map()`):** Transformación de datos crudos antes de renderizar.
- **Peticiones Asíncronas (`fetch` / `async-await`):** Consumo de APIs públicas externas para listar datos en tiempo real.

---

## Tecnologías Utilizadas

- **HTML5:** Estructura semántica.
- **CSS3:** Flexbox y estilos globales.
- **JavaScript (ES6+):** Lógica, eventos del DOM y `fetch`.
